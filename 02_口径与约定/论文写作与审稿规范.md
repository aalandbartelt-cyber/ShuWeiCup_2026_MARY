更新：2026-11-20（北京时间）。本文件汇总用户在第一问建模、绘图和成稿期间提出的意见、已实施修改，以及第二、三问必须复用的检查方法。后续写稿、绘图、整合、审稿前必读；与[图表规范](图表规范.md)共同使用。

本项目的用户最新指令优先于通用 skill 建议。下文的字号、插图比例、假设数量和图数，明确区分用户要求、当前实现与一般建议；不得把本次排版选择冒称比赛官方规定。新反馈应更新对应条目和交接记录，避免多份文档互相矛盾。

## 1. 当前必须保持的状态

1. **全文框架服务于三问。** Introduction、Problem Analysis、核心假设与符号、目录均按全文组织。问题重述分别写 Problem 1/2/3；问题分析分别写 Analysis of Problem 1/2/3。
2. **Summary、Keywords 继续空着。** 三问完成后统一撰写；不得因通用 skill 建议尽早写摘要而自动补入当前稿。
3. **第 7 节 Model Evaluation、第 8 节 Conclusion 只保留标题。** 正文以及原 7.1、7.2 均已清空，最后按全文写。各问自身的验证、负结果和适用边界仍留在对应问题的结果段。
4. **附录 A 暂不整理，最后再做。** 已有内容保留，不宣称已定稿；补充图表暂归附录 B。
5. **第二、三问未完成的结果不提前填写。** 当前章节位置和待补说明保留；实际求解完成后再逐项补齐。
6. **当前改动写入待审目录。** 本轮文档归纳不改变正式件所有权或发布权限；继续遵守根目录 `AGENTS.md`。

以上是当前写作阶段的约定，不是最终投稿可以缺少摘要、结论或完整三问答案的依据。三问完成并进入全文收尾时，再统一补齐暂缓项。

## 3. 第二、三问的写作步骤与交付清单

### 开始前

读根目录 `AGENTS.md`、本规范、图表规范、当前 handoff 和相关 skill；查看当前稿件与已有结果，确认哪些模型/测试已冻结。先写一行问题链：**上一问提供什么→本问决策/模型是什么→输出什么→下一问如何使用→验证依据是什么**。已完成实验不作为“未尝试方向”重复开展。

Q2 沿用 Q1 状态，明确遮蔽、请求、返回延迟、等待、误差/成本的定义；不能把密集观测下的覆盖率直接当成任意稀疏策略保证。Q3 要明确从许可前缀到工期分布再到调度决策的关系；位置半径不能直接改称工期区间，Q3 在线输入继续遵守题目数值前缀限制。这里是跨问口径提醒，具体模型与参数以实际方案和试验为准。

### 每问正文

依次回答：要解决什么；为什么选此模型；变量、目标、约束与假设是什么；使用什么求解器及设置；与谁在什么条件下比较；结果支持什么；何处失效；输出怎样进入下一问。正文保留核心公式和证据，诊断细节进入附录并建立交叉引用。简洁不能删掉比较条件、公式前提或重要负结果。

### 每次交付前

- [ ] 全文目录、三问前置分析和标题层次一致；未把局部结果写成全文总结。
- [ ] Summary、Keywords、第 7/8 节和附录 A 符合当前阶段约定。
- [ ] 普通段落缩进一致；公式后的符号解释顶格、符号就地定义；命题前提、证明和方框完整。
- [ ] 求解器、库版本、关键设置、停止/收敛情况、CPU/GPU 型号与日志一致。
- [ ] 数字、单位、分母、划分、比较方法及不确定性口径可追溯；已看过的测试不改称新独立测试。
- [ ] 图内 TNR 真实嵌入、无总标题/内部版本名；颜色和图例逐项对应实际图元。
- [ ] 重叠关系可从放大窗辨认，关键数值可直接读出；边框、箭头、图例和文字无裁切或遮挡。
- [ ] 按最终版面检查图宽和字号；图题简短、解释在正文；拆图后所有引用和面板字母已更新。
- [ ] 新增或移动引用后，文献按首次出现排序且无孤立条目；公式、表、图交叉引用已编译确认。
- [ ] 看最终 PDF 的目录、关键页及前后页，检查大块留白、浮动体和跨页断裂；全篇整合时逐页检查。
- [ ] 构建输入、源包与 PDF 对应；有变更就更新核验记录，不能沿用旧 PDF 的视觉审阅哈希。
- [ ] 更新 handoff：修改内容、最终路径、检查结果、未完成项和下一步；不把自动检查写成队员独立审阅。

检查结论写具体对象，例如“图例样式逐项对应”“拆图后的 4 个引用正确”，不要只写“格式已规范”“全部没问题”。

## 7. 第一问外部评审形成的后续要求（2026-11-20）

具体逐条证据见 [Q1 评审核查与修复](../docs/collab/reviews/Q1_评审逐条核查与修复_20261120.md)。以下用于 Q2/Q3 验收：

- 赛题本身不列入参考文献；删改条目后核对正文首次引用顺序与文献核验清单，不只修改编号。
- 明确区分拟合、误差评价、低质量分析和剔除用途，给出字段、连续性、质量及时间匹配规则与数量；用途可以重叠，记录数、区间数、时间戳和逐手样本不能混加。
- 按 UUID 核查去重，并检查环境、场景、操作者的跨划分重叠。采样间隔和断帧阈值须按实际记录频率解释。
- 物理单位和轴向只能由有效来源证实；人体身高字段的单位不能证明手坐标单位。训练尺度归一化不是物理单位转换；不能用猜测补齐评审缺项。
- 当前验证与训练 OOF 是 Q1 主证据；既有测试仅补充固定复核。保留真实冻结/查看时间线。Q2/Q3 整体模型、阈值、权重和偏好冻结后再查看各自测试结果，不能声称此前观察过的记录为全新独立测试。
- 主表须有同窗口、同参照、同聚合方式的常数/简单线性基线；同名方法还须核对速度回看跨度、阻尼参数和质量筛选，不能把不同实现默认为同一基线。
- 多跨度点预测、多跨度半径、密集观测校准和缺失观测校准是不同证据；图中必须同时呈现覆盖率和半径代价，不把原 0.1 s 条件半径外推成 Q2 保证。
- 视频增益以绝对值、事件数、逐环境差异和置信区间表达；区间包含零或事件稀少时使用有限、提示性的结论。置换对照必须保留可用性结构，不能靠制造不可能输入夸大退化。
- 失败案例单列，说明选择规则、原点及历史质量、目标是否合格；低质量目标处断线，不画出隐含插值。后验挑出的失败个案不能估计总体失败率。
