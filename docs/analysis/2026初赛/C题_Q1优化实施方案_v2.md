# C 题第一问优化实施方案 v2

日期：2026-11-20。用户已要求制定详细方案并实施。本文将深度评审的改进项转为可核查工作；不以某个新模型必然获胜为验收标准。

## 1. 目标与固定边界

目标是完成可用于论文与第二问的第一问优化版本：共同状态、可解释动态、观测质量发生与恢复、同版预测不确定性、任务/环境/阶段差异、视觉证据、完整验证及复现产物。

- 保留 v1 及其结果，v2 写 `artifacts/c_q1_v2/`；诊断/候选与最终选定模型分开记录。
- 双手 21 点几何中心和速度仍为 12 维状态，相对向量为派生量；不把手状态解释为商品状态。
- 官方训练/验证/测试环境划分不变。训练拟合与分组交叉检验、验证选择；最终模型、阈值和指标冻结并留哈希后才评价 Q1 测试。
- 不用未来片段终点、未来质量或未来像素计算当前预测特征。回顾性任务/阶段解释单列。
- 原生位置单位与独立物理精度边界保持；不伪造人工核验。人工标注是独立证据补充，未回填时写明范围，自动/AI 图像核查不得冒称人工真值。
- 图内 Times New Roman，语义色板，图题和解释性图注外置；PDF/SVG/600 DPI PNG，实际字体与视觉核查。

## 2. 实验协议（运行前固定）

| 项目 | 固定约定 |
| --- | --- |
| 预测跨度 | 1/30、0.1、0.2、0.5、1.0 秒；0.1 秒为主，其他为迁移/失配检查 |
| 目标时间 | 选择离目标时刻最近的真实样本，容差为记录中位间隔的 0.55 倍；必须晚于起点；越界剔除并计数；不插值制造参照 |
| 历史 | 起点至少已有 0.4 秒历史；历史特征只从不晚于起点的样本构造 |
| 公平比较 | 每一跨度、手和分层内相同起点、目标与资格；误差参照必须未标坏且有限 |
| 汇总 | 手在记录内等权，记录在环境内等权，环境等权；并保留每记录和每环境结果 |
| 点预测指标 | 平均欧氏误差、P90、相对训练手尺度误差；逐环境配对变化与困难历史分层 |
| 不确定性 | 每手三维预测球；50/80/90/95% 覆盖和半径，径向分位损失；双手联合覆盖另算，不混称 |
| 质量目标 | 每手和任一手的未来原始坏标记；分正常→异常、持续、恢复；新发事件报告提前量/召回与误报时间占比 |
| 阈值 | 预警阈值由训练侧留环境预测按预定误报水平选定；不得在验证/测试真值上反向优化阈值 |
| 不确定性拟合 | 训练侧留环境残差，选定超参数固定；不把重复帧当独立环境，不承诺不满足假设的分布无关覆盖 |
| 消融 | 单参数收缩、历史时长、质量标记、持续时间、运动特征、头部/腕部视觉、图像采样率分别对照 |
| 失败案例 | 按预定最大误差/失校准规则选例；同时保留代表性普通案例，说明选择依据 |

## 4. 模型选择与停止规则

点预测先按验证环境等权的归一化主跨度误差选择；保留全跨度结果，若最优方法随跨度变化，则采用预先定义的跨度查表/插值接口并逐项验证。复杂模块须对强简单基线有可解释收益；差异微小时优先更简单方法。质量模型按 Brier 与校准为主，同时报告事件发现与排序，禁止只挑有利指标。

预测集合的选择兼顾覆盖与半径；不能用无限扩大区间掩盖失配。最终 Q2 接口必须调用选定预测器及其对应尺度/分位，而不能拼接两个不同模型的最优数字。

冻结前所有候选均在训练/验证上完成；冻结后测试结果即使不好也如实报告，不按测试结果再次选模。外部人工标签尚未回填时，模型只主张对原始合格记录/质量标记的表现；需人工参与的独立验证单列为待补证据，不冒称完成。
