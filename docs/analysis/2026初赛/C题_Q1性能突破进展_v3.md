# Q1 v3 性能突破：当前证据与尚未解决的部分

2026-11-20，开发与固定组件复评报告。**v3 数值预测/半径组件已于 09:32 UTC 冻结，并完成旧测试集上的固定版本复评；质量/视频仍在训练与验证侧开发，整体目标继续推进。** 本文给出已运行结果；计划和未运行方法不能计入贡献。

## 1. 当前判断

状态预测已取得比 v2 更明显、跨环境更一致的改善。条件区间提高了 EgoPro 验证覆盖，同时缩小平均半径。视频确有与时间对应关系有关的信号，但现有融合方法的泛化收益仍不够稳定；不能把验证集的正结果写成已解决的视频突破，也不能据此断言视频无用。

本地 RTX 5070 Ti Laptop 已实际用于 DINOv2 提取和神经网络训练，尚未使用 A100。当前实验可在本地完成，主要困难是环境迁移、稀少异常片段和视觉表征选择。

## 2. 状态预测：已超过“标量阻尼解释大部分收益”的原阶段

新方法把七个因果速度尺度和三个局部二次位移预测作为专家，用旋转不变特征产生标量组合系数；位移输出随坐标旋转等变。特征包含转向、手部形状、当前/历史质量、与头部和另一只手的距离，以及已到达参照值产生的成熟误差。训练直接优化欧氏距离，三个随机种子集成。没有使用预测时刻之后的图像或轨迹作为输入。

主跨度 0.1 秒，比较均使用相同合格目标、相同记录/手/环境加权：

| 比较范围 | v2 多尺度平均误差，原始坐标单位 | v3 平均误差 | 相对改善 |
| --- | ---: | ---: | ---: |
| 16 个训练环境的整环境留出 | 0.01010246 | 0.00959901 | 4.98% |
| 4 个官方验证环境 | 0.01168341 | 0.01079503 | 7.60% |
| 验证 EgoDemo | 0.01060550 | 0.00930077 | 12.30% |
| 验证 EgoPro | 0.01191083 | 0.01110876 | 6.73% |
| 验证 EgoStandard | 0.01546615 | 0.01523771 | 1.48% |

相对更强的单参数阻尼，v3 在训练环境留出改善 5.59%，在官方验证改善 8.74%。四个训练折均改善；按单个环境看，训练 15/16、验证 4/4 改善。训练最差环境仍退步约 2.52%，不能写成所有环境均改善。

以环境为单位进行 2000 次配对重采样，相对多尺度的误差改善区间：训练约 [3.20%, 6.85%]，验证约 [5.50%, 9.96%]。这是在已拟合预测和开发选参条件下的环境重采样描述，验证只有四个环境，不是新测试上的普适保证。

尾部也改善：逐手、逐记录计算 95% 误差分位，再按环境平均，验证从 0.030809 降至 0.028360；训练留出从 0.024061 降至 0.023421。此统计量是“各组分位的均值”，不是混合全部帧的单一 95% 分位。

固定 0.1 秒训练方案迁移到另外四个预设跨度，聚合误差均改善，但 EgoStandard 在 0.033、0.5、1 秒分别有小幅至约 3.75% 的退步。后续需要跨跨度共享/收缩，而不能针对一个验证环境硬设最优方法。

证据：`artifacts/c_q1_v3/numeric_oof/`、`horizon_transfer/`、`assessment/state_environment_bootstrap.csv`、`assessment/state_environment_gains.csv` 和尾部表。直接距离线性初始化的 L-BFGS 曾达到迭代上限；现已用相同目标的精确梯度/Hessian 与有界 Newton 复核，目标 0.2538656966 → 0.2538656297，投影梯度约 1.51×10⁻⁸。重训门控验证误差仅 0.279969 → 0.279958，说明初始化早已接近该目标最优，不能将继续迭代写成主要增益。记录在 `refined_state/`，原门控对照未被替换。

## 3. 区间：EgoPro 验证改善，且没有靠整体放大半径

条件分位模型从整环境留出点误差拟合，输入运动状态和已成熟的残差历史。成熟残差仅在对应参照值已到达且合格之后反馈。训练侧交叉拟合产生加性校准，再将数据集修正向总体收缩。下表是完整预测管线比较，两代点预测器不同，不能把全部收益单独归因于校准算法。

| 数据集 | v2 验证覆盖 | v3 验证覆盖 | v2 平均半径 | v3 平均半径 |
| --- | ---: | ---: | ---: | ---: |
| 总体 | 88.80% | 89.88% | 0.019727 | 0.018295 |
| EgoDemo | 88.15% | 89.37% | 0.017930 | 0.016048 |
| EgoPro | 88.14% | 90.13% | 0.019809 | 0.019035 |
| EgoStandard | 89.85% | 88.92% | 0.026028 | 0.023850 |

名义水平为 90%。总体 pinball 损失从约 0.001803 降至 0.001680；EgoPro 约 0.002040 → 0.001836。EgoStandard 的覆盖和分位损失退步，因此还需要最差组权衡。半径保持原始坐标单位，不擅自标厘米。

与同一 v3 点预测器的固定全局分位半径比较，条件模型的总体覆盖 87.09% → 89.88%，半径 0.019084 → 0.018295，分位损失 0.002629 → 0.001680。这才是控制点预测器后的校准比较。

**上表本身不能证明“旧测试 EgoPro 82.04% 已被修复”。** 82.04% 是 v2 已观察测试；90.13% 是 v3 开发验证。随后对已冻结数值组件进行的复评见第 8 节，不能混淆两者。稀疏回传时也不能继续使用实际未收到的残差；新校准尚未接入完整 Q2 回放。

证据：`artifacts/c_q1_v3/calibration_screen/`。条件保证所需的交换性等假设未被证明，因此只报告经验覆盖。跨分位单调性、最差环境和罕见状态已继续检查，见下方新增结果；其他跨度和稀疏接口仍待完成。

### 3.1 延迟反馈与严格嵌套环境复核

新增覆盖反馈只在合格参照到达后，比较当时实际发布的半径与误差，再更新对数乘数；不追溯修改已发布半径。首次更新使用预先声明的 1/30 秒单位，不读取全记录的未来采样间隔。输出按名义概率累积取最大，保证 50%/80%/90%/95% 球嵌套；原始条件分位在验证中约 0.40% 行有交叉。

`calibration_nested/` 的外层留环境完全排除于内层点预测、条件分位和分组修正拟合；共额外训练 12 个内层点预测划分、每划分 3 种子。相较前期只对残差做再次交叉拟合，这一审计排除了外层环境对训练残差生成器的影响。反馈率 0.01 时，90% 球训练外层覆盖 89.86%、平均半径 0.017118、分位损失 0.001362；验证覆盖 90.06%、半径 0.018715、损失 0.001671。

| 90% 球、无额外标坏下限 | 无覆盖反馈 | 反馈率 0.01 |
| --- | ---: | ---: |
| 训练外层最差环境覆盖 | 87.46% | 88.65% |
| 训练环境覆盖偏离 90% 的平均绝对值 | 1.44 个百分点 | 0.50 个百分点 |
| 验证最差环境覆盖 | 88.40% | 89.38% |
| 验证环境覆盖偏离 90% 的平均绝对值 | 1.15 个百分点 | 0.68 个百分点 |

更快反馈可进一步缩小环境偏差，但增大半径与分位损失；不能仅按覆盖达标选择无限扩张。完整六档速率和条件表在 `feedback_screen/`、`calibration_nested/`。这些仍是开发结果，未把旧测试当作新验证集使用。

### 3.2 当前已标坏状态不能被总体覆盖掩盖

在未来参照合格的前提下，当前已标坏样本只有训练 219 个、10 个环境，验证 78 个。无专门修正时，该组覆盖约 82%，即使总体约 90%。新候选在条件半径上设置“当前标坏训练 OOF 误差的同水平经验分位”下限；各外层只用其内层残差估计，不能读取外层环境的结局。

| 当前标坏组、反馈率 0.01 | 无标坏下限 | 加标坏下限 |
| --- | ---: | ---: |
| 训练外层覆盖 | 81.62% | 89.38% |
| 训练外层平均半径 | 0.035825 | 0.059588 |
| 训练外层分位损失 | 0.006677 | 0.008468 |
| 验证覆盖 | 82.34% | 95.09% |
| 验证平均半径 | 0.043106 | 0.063877 |
| 验证分位损失 | 0.004933 | 0.004833 |

这一保守修正的代价必须保留：训练罕见组的损失变差，验证覆盖偏高，不能写成所有指标同时改善。对全部样本的影响较小：训练外层总体覆盖 89.88%、半径 0.017156；验证总体覆盖 90.08%、半径 0.018731、损失 0.001663。验证 EgoDemo/EgoPro/EgoStandard 覆盖为 89.70%/90.09%/90.25%。证据 `flagged_calibration/`。

该消融先将基础分位嵌套，再加可选下限、执行延迟反馈，并再次嵌套。与前面的“原始基础分位直接反馈”顺序不同，因此只在本消融的 True/False 两行间归因下限效果。两类流程都不提供任意条件覆盖保证；高速和罕见标坏状态仍需单列报告。

## 4. 视频：已运行的扩展及其真实增量

已完成全部 166 个训练/验证视频、74100 个 15 Hz 抽样帧的冻结特征提取。输入包括全图、逐手 ROI、DINOv2 外观、过去到当前的 Farneback 运动、模糊/曝光/边缘距离、投影一致性和检测历史。头部视角按当前可用三维位置关联手；腕部两个 ROI 作为无序集合，未伪称已知其解剖身份。PCA 只拟合训练视频。

| 实验 | 当前结果 | 判断 |
| --- | --- | --- |
| 点预测：冻结数值模型 + 视频诊断残差 | 验证误差额外降低约 0.54% | 小幅正信号；改为训练 OOF 数值底座后增益消失，尚不稳定 |
| 点预测：全图/局部 DINO 外观、时间差分、联合 | 多数低于纯数值底座 | 已运行，不能写成未试；更大特征维数没有自然带来增益 |
| 区间：视觉条件分位 | 当前所有扩展均未超过数值条件分位的总体损失 | 需要更有针对性的视觉误差表征 |
| 四状态质量：数值/诊断网络等权融合 | 验证 Brier 0.014262 → 0.013770，改善 3.45% | 验证 EgoPro/Standard 均改善；训练整环境 OOF 0.005779 → 0.005981，反而退步，不能入选为已证明的最佳主模型 |
| 视频负对照 | 正确对齐混合 0.013770；延后 1 秒 0.013842；延后 2 秒 0.014241；记录内置换 0.014255 | 时间对应关系有贡献，但不能排除开发选参和环境迁移问题 |
| 双手共享、强收缩的少参数概率修正 | 训练 OOF 视频 0.005745，数值 0.005750，基准 0.005779；验证视频 0.014207，数值 0.014259，基准 0.014262 | 两个范围均有正向微小增量；幅度仍不足以称为突破，且 AUC/AP 并非全面提升 |

神经质量融合的验证增益主要来自当前已标坏样本的恢复判断；其新发异常排序并未全面改善。坏标记是题目提供的标记，不能直接作为物理准确率真值。负对照中的记录内置换是专门的非因果破坏实验，不作为部署输入；延后对照只用过去帧。

少参数模型按训练环境 OOF 的 Brier 排序选正则强度，结果支持共享与收缩的方向。逐关节运动、形状变化和视觉位置修正现已实际运行，新增结果如下。

### 4.1 逐关节、双目和较长跨度：已运行结果

从 124 个头部视角视频提取了每手 79 维二维形状/弯曲/指尖距离及关联质量，加入过去 2/15、4/15 秒变化，双视角共 486 维；未把 MediaPipe 的深度当作真实三维位置。双目位置用两条世界射线的最近点中点，只有两帧及各自位姿都已到达才可用。检测可用率和与提供坐标的偏差因记录不同，未声称独立物理核验；镜头畸变尚未修正。产物 `articulated_video/`、`articulated_features/`。

## 9. 视频增量转向新发事件预警

### 9.1 序列模型已实际运行

`sequence_h0.1/` 与 `sequence_h0.5/`：过去 0.7 秒的八个时刻，双手共享 GRU16，纯数值/诊断/逐关节形状，同容量、两档正则、三种子，外层整环境 OOF、内层先验拟合。所有序列仅作向过去查询，记录间重置；源码在产物中快照保存。结果未超过既有较强数值/匹配模型，故不因“序列深度学习”名称而入选。

### 9.2 窗口内新发事件与终点坏标记是不同目标

当前两手均正常时，未来 0.5 秒内至少出现一次新坏标记，定义为新发事件。训练有 762 个阳性起点，验证 215 个；只看 0.5 秒终点时分别只剩 348 和 97 个阳性，遗漏了窗口内已发生并恢复的事件。新模型直接拟合前者，不能把它的概率或指标冒充原终点四状态概率。

固定同容量 LightGBM：150 棵树、7 叶、最小叶样本 200、学习率 0.03、L2=20。视频增量来自当前/过去的模糊、边界、相对运动、检测与投影一致性等诊断；当前输入不含未来质量或像素。15 叶对照保留，7 叶在训练 OOF 和验证 Brier 均较好。

| 0.5 秒新发事件 | 数值 OOF | 视频 OOF | 数值验证 | 视频验证 |
| --- | ---: | ---: | ---: | ---: |
| Brier | 0.014269 | 0.013990 | 0.038553 | 0.037945 |
| 平均精确率 AP | 0.034893 | 0.066384 | 0.141873 | 0.202065 |
| ROC AUC | 0.594582 | 0.685335 | 0.691887 | 0.708890 |

相对同容量数值模型，Brier 改善 1.95%（OOF）和 1.58%（验证）；AP 约提高 90.25% 和 42.42%。环境配对重采样 2000 次的 Brier 改善区间分别为 [0.57%, 3.78%]、[−1.13%, 3.58%]；训练 10/16、验证 2/4 环境改善，验证区间包含零。不能宣称所有环境都有效。

阈值由训练 OOF 的正常负例分位确定。在名义 5% 训练误报阈值下，验证数值模型检出 14/22 个事件、环境加权实际误报比例 13.33%；视频模型检出 16/22 个、实际误报比例 7.12%，中位提前量约 0.33 秒。名义阈值不是测试或验证实际误报保证，两个数字必须一并报告。

`onset_h0.5/audit/` 的固定模型负对照：正确视频 AP=0.2021，延后 0.5/1/2 秒为 0.0565/0.0812/0.0684，记录内置换为 0.0719；Brier 同时变差。置换只是破坏对应关系的非因果对照，不是可部署方法。0.1 秒同类新发模型也已运行，验证优势没有 0.5 秒一致，保留在 `onset_h0.1/`。

这是目前最明确的视频用途：较长窗口的新发事件预警。该阶段之后的固定复评、图文与接口已完成，见第 10 节；原终点质量模型与新预警模型保留各自任务定义。

### 9.3 流式接口

`q1v3_online.py::StreamingBallState` 保存当时发布的半径，仅在显式传入、已到达且合格的参照上更新。时间不允许回退；缺失参照不产生更新；延迟或乱序返回不倒灌未到达信息。`q1v3_interface.py::Q1V3` 可读取固定点模型、条件分位，并从调用方披露的前缀预测；38 个真实验证记录的固定审计点与批量预测的最大位置差约 5.35×10⁻⁹。`interface/verification.json` 明确标记密集完整覆盖回放和稀疏校准仍待完成，不能将点特征一致性扩大解释为全接口已验证。
