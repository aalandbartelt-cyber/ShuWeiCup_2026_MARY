## 3. 固定协议与统计口径

沿用 `configs/c_protocol.json` 的用户批准条件，新实施细则写独立 Q2 配置，保留原文件历史。

| 设置 | 取值 |
| --- | --- |
| 状态 | 双手 21 点中心、速度；相对向量派生 |
| 窗口 | 主 0.2/0.5/1.0 s，压力 2.0 s |
| 请求上限/单次费用 | 0/1/2/4；1 抽象费用单位 |
| 延迟 | 主 0.1 s；敏感性 0/0.3 s |
| 采样与返回 | 请求时刻已有样本；到达时刻 = 请求时刻 + 延迟 |
| 请求并行 | 主允许多个在途；单在途为消融 |
| 窗口起点 | 从 1 s 起，每 2.5 s 一个标称起点，向前取最近已有双手时刻为起点 |
| 窗口状态 | 以完整真实前缀独立初始化；遮蔽起点之后到窗口结束的样本 |
| 人工遮蔽参照 | 主实验双手整个目标窗口有限且质量合格；保留每个排除原因 |
| 主误差 | 每代表点欧氏距离的均值，不是 MSE；另报尾部误差 |
| 聚合 | 先窗内时间/双手，再记录内窗口，再环境内记录，最后等环境；各条件分开 |
| 归一化 | 训练环境估计的手部尺度；原坐标单位结果同时保留 |
| 覆盖/容许误差 | 主 90%，补 50/80/95%；容许误差为训练手部尺度的 0.5/1/2 倍 |

人工遮蔽窗口的合格参照由评估器选择，不把未来质量标记提供给策略；各方法同一窗口。不同长度主结果各用合法窗口，误差增长另给共同起点完整子集。自然非随机低质量区间独立分析，不能外推人工遮蔽误差。

### 渠道与事件定义

1. 付费数值包包括该原时刻双手位置/姿态（实现中仅传模型实际需要的列）、质量标记，以及不晚于请求时刻的最近头部/相机位姿。每个字段保留自己的原始采样时间，不插值。
2. `all_modalities_hidden` 无持续图像；`numeric_missing_video_available` 另外允许当前已可用视频。每次付费返回通道与费用相同，视频计算代价另报。
3. 策略只在原有双手时刻请求；当前先交付已到期观测，再决策；零延迟请求当场返回，然后记当前预测。每时刻最多一次请求。
4. 请求时扣费，不因数据标坏或窗外返回退费。策略排除不能在最后评分时刻前返回的请求；回放器仍能记录人为提供的合法晚请求，用于边界测试。
5. 预测持续进行；等待指标为窗口内至少一个请求在途的时间并集。另报延迟总和、及时返回数、窗外返回数、当前位置直接可见的评分数。
6. 预测器/策略不得持有 Recording、原始文件、参照数组或未来语义区间。只有回放器能读隐藏样本，生成两个隔离输出：可见信息接口、仅用于事后打分的轨迹。
7. 零延迟误差可能为零，必须单独报告非当前直接观测时刻，不能借此放大“缺失预测能力”。

## 4. 实现与求解

### 4.1 回放与数据审计

新增 Q2 回放模块，不替换冻结 Q1 组件或旧原型。接口包括只读观测历史、请求采样/到达时间、剩余预算及队列、带目标时间的预测、独立评价日志。为每个窗口保存唯一键、起点、终点、原样本范围、样本计数及筛选口径。先 train/validation；test 只在整体冻结之后生成和评估。

训练环境重新构造四个环境数均衡且尽可能覆盖数据集的折，保存明确列表；所有标准化、噪声、尺度、门控、残差和价值模型均遵循外层环境隔离。不能用全训练尺度/噪声冒充严格外层留出。

### 4.2 状态预测

基线：常数保持、两点速度、质量加权卡尔曼、训练选择的阻尼速度，以及 Q1 冻结迁移。卡尔曼按测量采样时间更新，再传播至当前时刻；不能把延迟样本当当前测量。

首轮主候选：

- 稀疏历史门控：实际时间间隔、各通道年龄、有效历史数、质量和运动变化；运动专家包括多时间尺度速度、二次趋势、阻尼速度。直接最小化尺度归一化欧氏距离。
- 缺失时间编码 GRU：位置以最新披露位置为基准，输入缺失/时间间隔与有效性掩码，比较 32/64 隐藏维；区别于 Q1 的普通短序列概率 GRU。
- 连续时间 CRU：因果外推，比较 8/16 潜在维。先核验作者实现和数值稳定性，不能把插值任务结果当作预测。

训练样本覆盖无请求、周期/随机请求、不同预算/延迟、连续缺失和稀疏返回。2 s 另训练验证，不沿用未经验证的短期半径。PyTorch AdamW，首轮 lr=1e-3，max_epochs=80，训练环境内 patience=10；三种子 20261120/21/22。超参数由训练内筛选/官方验证确定，表现提示瓶颈后扩展候选并写明理由。

### 4.3 校准与建议时长

从整环境留出回放生成欧氏残差，使用 LightGBM 条件分位拟合（初始 leaves 7/15/31，min_child_samples 100，lr=.03，最多 500 棵、训练内早停）。特征为可见运动、质量、历史间隔、预测跨度、已到达残差；视频分支仅用合法图像特征。

报告覆盖率、平均半径、分位损失与环境/时长/质量分层。保留静态分位基线及延迟成熟残差消融。任何反馈只在请求的合格参照真实到达之后更新，不喂评估器的每帧隐藏残差。

给定容许误差，以条件半径的未来上包络求最长建议预测时长，报告实际越界比例与区间最大误差。逐点名义覆盖不是整条轨迹同时保证。视证据补充独立的窗口最大残差校准；即使增加，也单独验证选择时长后的覆盖。

### 4.4 观测价值策略

主目标同预算下最小化后续平均欧氏误差。训练反事实从同一个已披露状态分别执行“请求/等待”，随后按相同后续策略推进至窗末。收益标签为两分支误差与费用之差，只有训练回放器可读未来作监督；部署特征只来自当前可见历史、点预测、剩余时间/预算和在途队列。

LightGBM 拟合行动收益差，周期策略初始化；第一批三轮策略改进，每轮新增自身访问状态。继续轮次由留出收益及失败诊断决定。费用权重首轮 {0,.03,.1,.3}，主结果 lambda=0，同预算；其他权重给误差—费用前沿，等待时间独立展示。

周期对照验证相位 {0,.25,.5,.75}；周期长度按可及时返回的区间与预算确定，投到真实时间戳并去重。阈值对照训练尺度阈值 {.25,.5,1,2} 和最小间隔系数 {.5,1,2}；同样允许并行在途，避免用失真的弱基线。

同预测器比较三策略；同策略比较预测器。另做忽略延迟、忽略队列、单在途和去掉质量信息消融。最终覆盖修正独立于价值策略输入，避免校准半径改变后又暗中改变策略。

### 4.5 视频与自然缺失

纯图像检测/质量/背景补偿光流/帧龄先实现，核验原缓存中每个字段。持续图像不能带入隐藏三维投影、头部位置、相机外参或未来左右匹配。腕视角无可靠解剖身份时无序池化。CoTracker 在线特征记录处理块末时刻与实际可用时刻；离线双向输出不作为在线信息。

同数值底座比较视频、错时和置换，记录CPU/GPU实际执行及延迟。根据失败分析决定进一步视觉模型/微调；不为“GPU分析”措辞虚写运行设备。自然坏标记分析发生、持续、恢复及首尾截断；没有独立真值不做位置误差。

## 5. 持续优化、实验选择与资源

每轮输出：当前最好结果 → 瓶颈环境/时长/质量/运动类型 → 有机制依据的改进假设 → 同条件对照 → 结果及下一步。三种子和配对环境差异判断稳定性，报告最差环境和退步条件。优先排查数据/接口/训练分布/目标函数，再根据证据扩展模型。

停止探索需要主要失败模式已经分析、有价值方向已有实际验证、剩余方向缺少稳定收益证据或不适用于本题；不能只因初始清单跑完就收尾。保留失败试验与未实施方向的理由。最终把完整预测、校准、策略、图像接口一同冻结，在已观察过的官方测试记录上固定复评。

默认本地 NVIDIA GeForce RTX 5070 Ti Laptop GPU；当前 Python 3.10.19、PyTorch 2.12.0.dev20260310+cu128、LightGBM 4.6.0。SciPy/NumPy用于数值基线，PyTorch用于训练，LightGBM主要CPU。真实需要A100时说明任务/显存/运行安排；没有实际使用就不写入论文。
