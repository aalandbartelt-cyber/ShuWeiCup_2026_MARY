# 第一问 v3：预测、条件校准与视频增量的性能突破

2026-11-20。用户明确要求继续优化三项性能，以尽可能做到最好为本轮目标；仅补文档、增加图表或重复确认简单基线不构成本轮完成。此方案保持完整目标，不预设新方法必然成功。

## 目标和比较口径

1. 状态预测：在同目标、同资格下超越两点、标量阻尼及 v2 多尺度，重点处理状态变化、噪声与环境差异；同时看平均误差、尾部、各数据集和各环境，避免只优化总均值。
2. 不确定性：改善低覆盖环境/运动条件的校准，在覆盖与半径/分位损失之间取得更好的权衡；不以无限扩大球半径达标。
3. 视频：实际利用外观、运动、遮挡和多视角证据，通过同等数值输入的消融证明增量。除了坏标记概率，也检验状态预测、位置误差尺度、失效预警的增量，不能把一个稀疏标记目标的负结果泛化为视频无用。
4. 图例：现有七组图及新增图的编码必须可解释，保持 Times New Roman、无图内标题、固定语义配色及外置图注。

## 数据隔离与真实性

- 保留 v2 冻结模型/测试/原图，不覆盖其证据。v3 新目录 `artifacts/c_q1_v3/`。
- 官方 train 55 条、16 环境用于拟合与分组交叉验证；validation 7 条用于开发选择。环境不可拆成随机帧训练/验证。
- v2 测试已被观察。本轮任何后续测试复评均明确标注为“已观察测试上的固定版本再评估”，不再声称完全未见；模型筛选与参数选择使用训练侧分组证据和官方验证。
- 视频仅用不晚于预测时刻的像素。光流仅过去→当前，时序网络仅看历史窗口；成熟残差只能在参照样本已到达且合格后反馈。缺失回放不补读隐藏值。
- 测量单位、坏标记与独立物理真值的区别沿用既定说明。人工核验不伪造。

## 实验路线

| 路线 | 具体候选 | 验证重点 |
| --- | --- | --- |
| S1 强化动力学 | 更多时间尺度；因果局部多项式/加速度；已成熟残差的在线阻尼与偏差更新 | 相同预测时刻；噪声与转向条件；是否优于标量基线 |
| S2 自适应预测 | 旋转等变的速度组合门控网络；直接优化平均欧氏误差；低维残差学习/混合专家 | 环境分组、训练种子、复杂度消融、尾部及跨环境退化 |
| V1 视觉几何/时序 | 逐手关节形状、边缘距离、双手/物体交互、投影残差变化、检测历史；跨视角一致性；图像模糊/曝光和运动补偿 | 同一数值底座，区分缺失/无检测/离屏，不把检测置信度当真值 |
| V2 冻结深特征 | 官方 DINOv2 小型骨干：全图与逐手局部；逐时刻特征及历史差分；必要时 RAFT 或跟踪特征 | 代码/权重固定哈希，本地 GPU，特征提取不接触标签，ROI 不用未来坐标 |
| V3 时序融合 | 数值主干 + 视觉残差/门控；浅层时间卷积或 GRU；正常/异常条件不同子任务；有根据再局部微调 | 纯数值、几何、外观、运动、联合及视频置换/错时负对照 |
| U1 条件校准 | 直接学习欧氏残差的条件分位；数据集/运动条件的收缩校准；成熟残差的因果在线适应 | 分组残差、覆盖—半径、最差组；不套用不满足假设的覆盖定理 |
| U2 视频校准 | 视觉失配/遮挡特征辅助误差尺度和分位模型 | 相同点预测器、相同校准样本，量化视频带来的区间增量 |
| F 图例 | 全称、参考线定义、区间类型、双重编码、作用面板与阈值 | 每图图例契约、实际导出文字及最终尺寸视觉检查 |
