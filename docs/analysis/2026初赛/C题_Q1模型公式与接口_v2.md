# 第一问 v2 模型公式与可调用接口

2026-11-20，AI 辅助整理。与 `artifacts/c_q1_v2/freeze.json` 对齐；测试后未重选模型。原生坐标单位不转换为厘米。

## 1. 共同状态

第 h 只手的第 k 个三维点为 p，几何中心及共同状态定义为

\[
c_t^h=\frac1{21}\sum_{k=1}^{21}p_{t,k}^h,\qquad
x_t=[(c_t^L)^T,(v_t^L)^T,(c_t^R)^T,(v_t^R)^T]^T.
\]

这里的速度是模型导出量；原始观测与推断状态必须区分。相对位移为 `c_right − c_left`，不增加独立自由度，也不是商品位置。

## 2. 因果多尺度预测

历史端点为最接近当前时刻减去指定时长的已有样本，且严格早于当前样本；并不读取未来位置。令四个历史时长为 1/30、0.1、0.2、0.4 秒：

\[
v_{t,j}^h=\frac{c_t^h-c_{s_j(t)}^h}{t-s_j(t)},\qquad
\widehat c_{t+\Delta}^h=c_t^h+\Delta\sum_{j=1}^4 a_j(\Delta)v_{t,j}^h.
\]

系数由训练环境/记录等权的归一化目标速度平方损失拟合，加入向两点速度 `[1,0,0,0]` 的岭收缩。训练要求当前、四个历史端点及目标均未标坏；评估要求目标未标坏，同时单列历史曾标坏条件。尺度来自训练集手几何尺度。主跨度系数为 `[0.965074, −0.025270, −0.062797, 0.016529]`，正则强度为 1。负系数允许补偿速度变化，不把它解释成概率权重。

常数、两点速度、单参数阻尼、质量滤波和向量版 1 euro 构成对照。1/30 秒选定质量滤波；其余声明跨度选多尺度。查询跨度之间插值的是两个端点模型各自在实际查询年龄下的输出及半径；因此只有声明跨度和额外回放得到直接验证，插值本身不是覆盖定理。

## 3. 残差尺度与预测球

每个训练环境的点预测由排除该环境的数据拟合。令 r 为该留出预测的欧氏误差除以训练尺度 H，z 为

\[
z=[1,\ \Delta\lVert v_{t,1}\rVert/H,\
\Delta\lVert v_{t,1}-v_{t,2}\rVert/H,\ b_{\rm sampled}]^T.
\]

`b_sampled` 表示当前或四个历史端点有坏标记。尺度回归采用非负最小二乘。用留环境拟合的尺度计算标准化残差分位数 q，并在最终训练残差上拟合尺度系数：

\[
R_{1-\alpha}(t,\Delta)=H\max(z^T\beta,10^{-4})q_{1-\alpha},\qquad
\mathcal B=\{u:\lVert u-\widehat c\rVert_2\le R_{1-\alpha}\}.
\]

这是每手三维经验预测球。覆盖率针对合格的原始数值参照，不等于物理准确率，也不等于双手联合覆盖。训练残差的分组结构、验证选参和环境迁移不满足简单独立同分布保证；因此同时报告实际覆盖、半径及径向分位损失。

## 4. 可靠性与事件指标

联合状态编码为 `bad_left + 2 * bad_right`。四状态概率分别对应均好、仅左坏、仅右坏、双坏；边际为

\[
P_L=p_1+p_3,\qquad P_R=p_2+p_3,\qquad P_{\rm any}=1-p_0.
\]

四折留环境预测用于温度拟合及事件阈值。概率模型预测未来时点标记；事件指标使用整个预测窗口内的新发或恢复，不能混用这两个目标。误报分位只用训练留出预测、当前处于风险集合且窗口内没有相应转变的时刻计算。并列分数采用严格大于阈值；报告迁移后的实际误报，而非承诺名义比例。

0.1 秒最终选择四状态转移频率，0.5 秒选择数据集频率；更复杂候选及其负结果完整保留。这反映当前目标和样本上的证据，不代表运动或视觉对其他可靠性定义无用。

## 5. Q2 接口示例

在仓库根目录、mathorcup 环境运行，设置 `PYTHONPATH=src`：

```python
from shuwei_c.q1v2_interface import FrozenQ1

model = FrozenQ1()
# time / centres / bad 只包含已回传的观测，时标严格递增。
belief = model.forecast(time, centres, bad, now, dataset="EgoPro")
risk = model.flag_risk(bad[-1], dataset="EgoPro", horizon=0.1)

# 仅对已检验的周期回传条件应用经验修正。
sparse_belief = model.forecast(
    time, centres, bad, now, dataset="EgoPro",
    response_pattern=(0.2, 0.1),  # 请求周期、回传延迟，单位秒
)
```

返回位置、每手半径、最近观测年龄、超过 1 秒的外推标志、校准适用范围和冻结哈希。稀疏修正乘数约 2.2159，但验证覆盖仍有不足；接口明确标注这一限制，不把乘数当安全保证。调用方不得在延迟期间补读未回传位置；回包内容必须来自请求时刻。
