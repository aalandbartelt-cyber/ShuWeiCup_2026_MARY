## 开源和视觉方法

- [FilterPy](https://github.com/rlabbe/filterpy/blob/master/README.rst)：读 README 的预测/更新接口，并打开 Kalman 源码作框架对照；当前状态空间实现自行编写，未把库示例的协方差数值照搬。该仓库不能替代本题的噪声辨识与对照。
- [1€ Filter 作者页](https://gery.casiez.net/1euro/)及[官方 GitHub](https://github.com/casiez/OneEuroFilter)：读方法介绍和调参说明。Casiez、Roussel、Vogel，CHI 2012，pp.2527–2530，DOI 10.1145/2207676.2208639。启发是显式处理平滑与滞后取舍；尚未加入本题实测比较，不宣称已复现。
- [MediaPipe 官方文档](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker?tab=Python)：核对 Python IMAGE/VIDEO 语义、输出空间、模型入口。已实际运行 1.2.3 的 IMAGE 模式，模型下载地址和 SHA256 在本地 provenance。世界关键点以手中心为原点，不能直接解释为记录世界坐标；左右手分类分数不是定位准确度。
- [HaMeR 项目](https://geopavlakos.github.io/hamer/)、[仓库](https://github.com/geopavlakos/hamer)、[论文](https://arxiv.org/html/2312.05251v1)：阅读项目说明、README 安装/训练/评价和论文 §3.1–3.5。输出 MANO 局部形状与相机参数，需要核验尺度和相机关系；MANO 模型文件单独获取。当前未训练/运行 HaMeR，不套用旧 CUDA 环境配方。
- Prakash 等，ECCV 2024，[论文](https://arxiv.org/html/2312.06583v2)、[作者开源仓库](https://github.com/ap229997/hands)：读摘要/引言、相机与视角相关方法、局限及 README。WildHands 提醒透视畸变、遮挡和视角差异；作者仓库已核对，不能把 fork 当独立验证。尚未运行本题微调。
- [AssemblyHands](https://github.com/facebookresearch/assemblyhands-toolkit/blob/main/README.md)：读数据与关键点约定；其 wrist 索引不能无依据移入本题 Demo/CSV。
- [OR-Tools 单机示例](https://github.com/google/or-tools/blob/stable/examples/python/single_machine_scheduling_with_setup_release_due_dates_sat.py)：读约束建模片段。该示例的已知工期、硬 due 与 makespan 目标不同于本题，不直接复用成求解结论。
- [Estimating Ego-Body Pose from Doubly Sparse Egocentric Video Data](https://arxiv.org/abs/2411.03561)：仅摘要。时空相关性及不确定性是后续增强候选，没有据摘要声称解决本题。

## 我们的 RoboCup 参考

本地 `01_参考学习/RoboCupHomeSim`，HEAD `9a5539ee045cb56a7db4e242d509c5aa77a073b9`。实际阅读 RockyV6.1 的 `decision.hpp`、`inspection.hpp`、`scheduler.hpp`、`belief.hpp` 接口与注释；本轮再次核对 belief/inspection。

可借鉴：将物理动作与获取信息分开；只依据已经得到的证据更新信念；计算预算耗尽不是不可行证明；决策先验不等同逻辑确定性。对应本题是区分原始标记、估计可靠性和真实物理准确度，以及 Q2/Q3 的信息边界。未移植私有规划器实现、场景、仿真得分或结论，不把 RoboCup 成绩作为本题验证。
