## 核验结果与文字口径

- 开发集 53,829 个双手时刻，107,658 个手—时刻观测，6,782,454 个坐标数值；不能把坐标数值当作独立样本数。
- 记录时长 5.93–173.97 秒。标坏观测共 750 个，占 0.697%；每记录比例为 0–4.784%。数据集分布与环境分组是不同口径。
- 原始手部坐标非有限项为 0，精确重复整条轨迹为 0，连续完全相同的双手帧为 0。因此不能声称进行了缺失填补、删重复或主观异常点修复。
- 预热排除 1,486 个手起点，记录终点限制排除 406 个；没有额外容差失败。105,766 个匹配目标中，105,057 个合格、709 个标坏。709 是该跨度匹配目标的计数，与原始 750 个标坏手观测分母不同。
- 标坏信息继续用于质量、新发事件及不确定性分析；未来标记只决定训练/评估标签资格，不提前提供给在线预测器。
- 166 个开发视频含 74,100 个抽样帧；其中 124 个头部视角含 54,038 帧。不能将所有视角的总帧数冒充最终头部视频模型的帧数。视频只作向过去匹配，数值尺度与标准化仍限于训练侧。
