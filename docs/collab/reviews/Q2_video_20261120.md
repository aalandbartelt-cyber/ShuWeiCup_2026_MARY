### 主线程集成接口（优先严格装载器）

```python
from shuwei_c.q2_video_provider import VerifiedVideoCache
images = VerifiedVideoCache('artifacts/c_q2/video/image_motion', kind='image')
provider = images.for_episode(episode, time_mode='nominal', processing_delay_s=0.)
snapshot = provider.at(now)  # 156维features、对应feature_names及source/available时间
# 传给 q2_replay.replay(..., video_provider=provider)
```

`src/shuwei_c/q2_video_provider.py` 为独立新增装载器，不改正在提取的源码/身份。它检查最终完成manifest与物理视角清单一致，并逐记录核对文件存在、哈希、帧数和特征列。真实没有腕视角才填缺失块，未提取完成的已有视角会报错。原 `VideoProvider.from_cache` 只适合单元/局部诊断，不作为正式全量入口。

`nominal` 表示帧或块末可用，不等于物理零耗时；`measured` 使用逐流测得的后处理服务时间；额外`processing_delay_s`可用于同条件敏感性。CPU图像`measured`仍不含复用的MediaPipe计算，必须单独说明。
