## 3. 自然低质量结果

这里的“自然缺失”是**数据提供的低质量标记代理**。标记恢复不等于独立证实物理定位恢复，不能将下列数字改写成真实遮挡或真实位置精度。

| 指标 | 训练 | 验证 |
| --- | ---: | ---: |
| 记录/环境 | 55 / 16 | 7 / 4 |
| 标坏手样本 | 591 | 159 |
| 连续坏标记段 | 113 | 37 |
| 已观察到起点的坏段 | 111 | 37 |
| 记录左端截断 | 2 | 0 |
| 记录右端截断 | 0 | 2 |
| 等环境标坏样本比例 | 0.4982% | 1.3086% |
| 每手每记录分钟发生率，等环境 | 1.8293 | 5.5968 |
| 完整坏段首次标坏到首次好标记中位时间 | 0.1000 s | 0.1000 s |
| 同口径 90% 分位 | 0.4333 s | 0.3267 s |
| 0.2 s 内再发比例（事件合并口径） | 39/113 = 34.51% | 10/35 = 28.57% |

三个值得进入问题二的数据事实：

1. 大多数标坏段较短，但一次好标记后很快再次标坏并不少见；可据此检验单次返回是否足以维持可靠状态。再发统计只能支持描述和训练内假设，不能作为线上可提前知道的标签。
2. 验证集的标坏比例和发生率更高，而且数据集/环境差异明显。验证 EgoDemo 两条记录没有坏段，不能给其虚构恢复时长；验证 EgoStandard 只有一条记录，不能把其 4.7842% 样本标坏比例称作稳定总体规律。
3. 首尾截断虽少仍必须保留。训练两个左截断段不能计为已观察到的起点；验证两个右截断段不能算“在记录末端恢复”。

### 时长口径

质量时间间隔约 1/30 s，最大间隔约 0.04 s。对连续标坏索引 `[s,e)`：

- 可见标坏跨度为 `time[e−1]−time[s]`，单帧段该值为 0。
- 首次检测到标坏至首次好标记为 `time[e]−time[s]`；末端无好标记时该恢复时长缺失，只有随访下界。
- 完整段采样界限为 `[time[e−1]−time[s], time[e]−time[s−1]]`。把这解释成连续时长界限需要相邻采样间无额外未观察状态反转的假设；它不是独立物理遮挡界限。
- 恢复后未满 0.2/0.5/1 s 就到记录尾的随访不计为“没有再发”。
- 比例同时给样本比例与按左端标记保持到下一标记的时间占比，后者仅是标记计时约定，不是位置插值。

产品极限曲线使用已观察起点的段，右截断保留，左截断排除；从首次标坏开始计时。曲线按事件合并，重复段存在记录/环境相关性，本次不提供假设独立事件的置信区间。删失独立性未由数据证明，作描述性结果；没有随访支持且尚未全部恢复的尾部返回缺失值。

原始方法核验：Kaplan EL, Meier P. Nonparametric Estimation from Incomplete Observations. JASA 53(282), 457–481 (1958), DOI [10.1080/01621459.1958.10501452](https://www.tandfonline.com/doi/abs/10.1080/01621459.1958.10501452)。作者原文的独立删失条件不能省略或自动视为本题成立。
